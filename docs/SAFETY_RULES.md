# Safety Rules

## Editorial Safety
- Never invent product specs.
- Never claim hands-on testing unless the product record is marked as personally tested.
- Prefer evidence-backed source linking for claims.

## WordPress Safety
- Never auto-publish.
- Draft status only for exports.
- Never modify published content without explicit approval.
- Never delete WordPress content through this app.

## Secrets
- Never log secrets.
- Never expose secrets to the frontend.
- Never commit `.env`.

## Workflow Safety
- Every workflow action must be reviewable via logs.
- Placeholder actions must clearly state that no external API call was made.
